# Float

!!! tldr "The Basics"
    - **Runs:** Tuesday AM and every other Friday AM at G3/346
    - **Arrive:** early enough to have prep done for an **8:00 AM** first case (sedation patients need consent + H&P in 10-bed)
    - **Primary role:** advanced procedures — biopsies, CT-guided injections, ablations, vertebroplasties (sometimes SI joints, since CT fluoro is available)
    - **Secondary role:** track cases for vertebroplasty conference
