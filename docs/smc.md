# Science Drive Medical Center

!!! tldr "The Basics"
    - **Arrive:** by **7:15 AM** to preview cases, help with the diagnostic list, and run the schedule with the sonographers from each room
    - **Primary role:** scheduled US and fluoro cases
    - **Secondary role:** ≥5 outpatient MR/CT off Sports/Spine, dictate radiographs, help with spine MRI, read your own MR arthrograms

## Workflow

- Ultrasound orders can be ambiguous. Preview the list to understand the indication for each diagnostic exam and procedure. Prep procedure cases per usual (correct site/side, previous imaging, allergies/meds/contraindications, etc.).
- Run the list with the sonographers in the morning to identify any issues and resolve them.
- Four fluoro injections are scheduled each day (covered by PAs on Tuesdays and Fridays). Share these with the resident.
- Before leaving, confirm with the techs that all MRI contrast exams are done (usually by 4:30).

---

## Tips

- Scan hands-on whenever possible — this is the only way to learn
- Running three rooms is busy. You'll get better with practice — keep the day moving and on track.
- As you get better, pick up radiographs and spine MRI to help decompress the list
